# SYSTEM: AWAKEN V3
Eine deutlich ausgebaute PWA-Version des Solo-Leveling-inspirierten Fitness-Prototyps.

## Neu in V3
- modernes Mobile-first SYSTEM UI
- Onboarding: Ziel, Erfahrung, Equipment, Trainingstage
- adaptive Quest-Belohnungen und Schwierigkeit mit dem Level
- XP, Level-Ups und E→D→C→B→A→S-Ränge
- STR / AGI / VIT / END
- Tagesquests mit sicherem Recovery-Konzept
- Streaks und Achievements
- Demo-Welt-Rangliste
- lokales Speichern per localStorage
- offline-fähiger Service Worker
- installierbares PWA-Manifest und Android-App-Shortcuts

## Start
Die Dateien auf einen HTTPS-Webserver hochladen und `index.html` aufrufen.
Danach kann Chrome die Website als App installieren, sofern die Installationsbedingungen erfüllt sind.

## Wichtig
Die Rangliste ist in V3 noch eine Demo. Für echte weltweite Nutzer, Login und Cloud-Speicherung braucht die nächste Version ein Backend.
